# Socially Different Lab Website

Official homepage concept for the **Socially Different Lab** at Peking University, formally the Laboratory of Social Difficulties and Associated Disorders.

## About

Socially Different Lab studies the mechanisms and intervention pathways of social difficulties through multimodal psychological science. The current single-page site introduces the lab's research themes, methods, team, selected publications, culture, shared resources, and opportunities.

## Local preview

Open `index.html` directly, or run a simple static server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Updating content

- Page content and member cards: `index.html`
- Visual design and responsive breakpoints: `styles.css`
- Member profile copy, profile dialogs, mobile navigation, section highlighting, and reveal effects: `script.js`
- Principal investigator portrait: `assets/muyu-lin.jpg`
- Team portraits: `assets/team/`
- Shared resource link: search for `disk.pku.edu.cn` in `index.html`
